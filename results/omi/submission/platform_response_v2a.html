Acute Coronary Syndrome (ACS) ECG Prediction Model Evaluation

Upload your prediction results for the 12-lead ECG ACS dataset and receive the corresponding evaluation metrics.

  • Metrics: Sensitivity, Specificity, PPV, NPV, Accuracy, F1-score.
  • Dataset size: Train 17,960; Test 1,995; Total 19,955.
  • Tasks covered: AMI/OMI, STEMI/NSTEMI/UA, CTO/PCI, among others.

Submission Format

  1. Upload a CSV file.
  2. The submission must include at least one identifier column: ecg_row_record or ecg_med_record. The identifier column(s) must match the corresponding column(s) in the test set test.csv: exactly the same number of samples and identical record names.
  3. The submission must include one or more label prediction columns, with values 0 or 1. Column names can be any subset of: AMI, OMI, CTO, PCI, NSTEMI, STEMI, UA, LM, PLAD, MLAD, DLAD, DB, PLCX, MLCX, DLCX, OM, PRCA, MRCA, DRCA, VF_VT, Paced, Prior_PCI.

Example (submission.csv):

ecg_row_record ecg_med_record AMI OMI
00001.dat 00001.med 0 0
00002.dat 00002.med 1 0
00003.dat 00003.med 0 1
